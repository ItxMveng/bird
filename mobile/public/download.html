Bird pour Android

Enchères entre voisins, paiement bloqué jusqu'à la remise en main propre.

Télécharger l'application (APK)

Dernière version disponible sur GitHub.

Installer en 3 étapes

  1. Ouvrez le fichier téléchargé bird.apk depuis les notifications ou le dossier « Téléchargements ».
  2. Si Android le demande, autorisez l'installation depuis ce navigateur (« Sources inconnues »).
  3. Ouvrez Bird, créez votre compte, puis rechargez des fonds de démonstration pour essayer une enchère.

Bon à savoir

Cette version de démonstration utilise des fonds fictifs : aucun paiement réel n'est effectué. L'application n'est pas publiée sur le Play Store, d'où l'avertissement de sécurité à l'installation. Vous préférez ne rien installer ? Utilisez la version web.
